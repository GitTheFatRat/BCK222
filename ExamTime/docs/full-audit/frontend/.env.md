# frontend/.env

## Muc dich (1-2 cau)
File này chứa các biến môi trường (Environment Variables) cục bộ dành cho Frontend. Mặc định nó chỉ chứa đúng một cấu hình: đường dẫn gốc (Base URL) trỏ tới API của Backend.

## Import / phu thuoc
- Không có.

## Noi dung chi tiet
- `VITE_API_BASE_URL=http://localhost:5000/api`: Do dự án sử dụng Vite làm công cụ build, mọi biến môi trường bắt buộc phải bắt đầu bằng tiền tố `VITE_` thì mới được phép rò rỉ (expose) vào bên trong code React. 
- Biến này trỏ thẳng tới cổng 5000 (nơi Backend Node.js đang chạy). Khi đem lên môi trường Production, biến này sẽ được thay thế bằng domain thật (ví dụ: `https://api.examtime.com/api`).

## Duoc su dung boi (dependents)
- Được truy cập thông qua cú pháp `import.meta.env.VITE_API_BASE_URL`.
- Cụ thể, các file `frontend/src/config/axios.js` và `frontend/src/config/media.js` sử dụng biến này để thiết lập gốc URL cho mọi lệnh gọi API và kéo tài nguyên tĩnh.

## Diem dang chu y (neu co)
- Cấu trúc rất tối giản và đúng chuẩn Vite. Không chứa bất kỳ thông tin nhạy cảm nào (như API Key, Secret) vì mã nguồn Frontend ohải được tải xuống trình duyệt của người dùng.
