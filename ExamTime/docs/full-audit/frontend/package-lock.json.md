# frontend/package-lock.json

## Muc dich (1-2 cau)
File này được npm tự động sinh ra nhằm khóa chặt (lock) phiên bản chính xác của toàn bộ cây phụ thuộc (dependency tree). Nó đảm bảo rằng dự án sẽ luôn chạy ổn định trên các máy tính khác nhau bằng cách cài đặt đúng y hệt một phiên bản thư viện mà không bị tự động nâng cấp gây lỗi tương thích.

## Import / phu thuoc
- Là "bóng ma" đi kèm với file `package.json`. Bất kỳ thay đổi nào trong `package.json` đều sẽ dẫn đến việc npm tự động cập nhật file này.

## Noi dung chi tiet
- Ghi nhận chi tiết từng thư viện, phiên bản chính xác (ví dụ: `19.0.0` thay vì `^19.0.0`), URL tải về từ thư viện npm (resolved), và mã băm kiểm tra tính toàn vẹn (integrity hash) để tránh tải phải mã độc.
- Đây là một file có thể dài hàng chục nghìn dòng và hoàn toàn do máy quản lý. **Con người tuyệt đối không bao giờ được chỉnh sửa trực tiếp vào file này.**

## Duoc su dung boi (dependents)
- Tiến trình `npm install`.

## Diem dang chu y (neu co)
- Đây là file tự sinh (auto-generated) nên không cần phân tích sâu hơn. Chỉ cần nhớ luôn luôn commit nó lên Git để cả team đồng bộ phiên bản với nhau.
