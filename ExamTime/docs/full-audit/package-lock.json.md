# /package-lock.json

## Muc dich (1-2 cau)
Tương tự như file `package-lock.json` của Backend và Frontend, file này khóa phiên bản các thư viện được khai báo trong file `/package.json` ở cùng thư mục Root.

## Import / phu thuoc
- Sinh ra tự động từ file `/package.json`.

## Noi dung chi tiet
- Chứa danh sách các gói thư viện con (sub-dependencies) cần thiết để chạy thư viện `multer` (do file `/package.json` yêu cầu `multer`).
- Hoàn toàn tự động, không được chỉnh sửa bằng tay.

## Duoc su dung boi (dependents)
- Tiến trình `npm install` khi chạy ở thư mục gốc.

## Diem dang chu y (neu co)
- Cũng như `/package.json`, file này là **tác phẩm của sự nhầm lẫn** khi thao tác với NPM. Lẽ ra thư mục Root không nên có hai file này. Ta nên xóa chúng đi để dự án gọn gàng và không sinh ra một thư mục `node_modules` thừa thãi bên ngoài Root.
