# backend/.env

## Muc dich (1-2 cau)
File này lưu trữ các biến môi trường (Environment Variables) cấu hình cho server Node.js. Nó giúp tách biệt các thông tin nhạy cảm (như mật khẩu Database, secret key) ra khỏi mã nguồn (source code).

## Import / phu thuoc
- Được load tự động vào Node.js thông qua thư viện `dotenv` (được gọi trong `backend/server.js`).

## Noi dung chi tiet
- `PORT=5000`: Cổng mạng (Port) mà server Express sẽ lắng nghe.
- `MONGO_URI`: Chuỗi kết nối (Connection String) trỏ đến cluster MongoDB Atlas trên cloud. Chứa username (`ExamTimeMongoDB`) và mật khẩu của database.
- `JWT_SECRET`: Chuỗi khóa bí mật dùng để mã hóa và giải mã JSON Web Token (phục vụ đăng nhập). Nếu thay đổi khóa này, tất cả các user đang đăng nhập sẽ lập tức bị văng ra (token cũ trở thành không hợp lệ).

## Duoc su dung boi (dependents)
- `backend/server.js`: Sử dụng `process.env.PORT` để mở cổng.
- `backend/config/db.js`: Sử dụng `process.env.MONGO_URI` để kết nối DB.
- `backend/middlewares/authMiddleware.js` và `backend/controllers/authController.js`: Sử dụng `process.env.JWT_SECRET` để xử lý token.

## Diem dang chu y (neu co)
- **Bảo mật**: File này tuyệt đối **KHÔNG ĐƯỢC** commit lên Git (đã được cấu hình trong `.gitignore`). Tuy nhiên, trong phiên bản hiện tại, nội dung mật khẩu thật của DB Atlas đang nằm rõ rệt ở đây. Nếu triển khai lên Production, cần đổi mật khẩu DB và `JWT_SECRET` thành chuỗi ký tự ngẫu nhiên phức tạp hơn.
