# /.gitignore

## Muc dich (1-2 cau)
File này dùng để khai báo cho hệ thống quản lý phiên bản Git biết những thư mục hoặc file nào không cần (và không nên) theo dõi (track) và đẩy (push) lên kho lưu trữ (như GitHub/GitLab).

## Import / phu thuoc
- Không có. Được đọc tự động bởi tiến trình `git`.

## Noi dung chi tiet
- Hiện tại file này đang **trống rỗng** (0 byte).
- Điều này là một **lỗ hổng cực kỳ nghiêm trọng** trong việc quản lý mã nguồn. Nó có nghĩa là nếu developer gõ lệnh `git add .`, toàn bộ thư mục `node_modules`, các file cấu hình chứa mật khẩu (`.env`), và các file build (`dist`) đều sẽ bị đẩy tuốt lên mạng.

## Duoc su dung boi (dependents)
- Tiến trình `git`.

## Diem dang chu y (neu co)
- **Kiến nghị (Recommendation):** Cần lập tức thêm các dòng cơ bản sau vào file này:
  ```text
  node_modules/
  .env
  dist/
  uploads/
  .DS_Store
  ```
